Completed Task 1 – AI Problem Design as part of my internship journey with @SWYNEX Technologies.

For this task, I designed an AI-based SMS Spam Message Classification problem using Machine Learning.

The goal is to classify SMS messages into two categories: Spam and Ham (Not Spam). I documented the target user, UCI dataset source, proposed TF-IDF + Multinomial Naive Bayes approach, constraints, risks and evaluation metrics.

I also prepared a Python baseline to evaluate the model using accuracy, precision, recall, F1-score and a confusion matrix.

This task helped me understand how to convert a real-world problem into a clearly defined AI problem with measurable success criteria.
