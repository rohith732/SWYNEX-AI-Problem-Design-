Completed **Task 1 – AI Problem Design** as part of my internship journey with @SWYNEX Technologies.

For this task, I designed and tested an SMS Spam Message Classification system using Machine Learning.

The goal is to classify SMS messages into two categories: **Spam** and **Ham (Not Spam)**.

I used the UCI SMS Spam Collection dataset (5,574 labelled messages) and built a baseline pipeline using TF-IDF text features and a Multinomial Naive Bayes classifier.

**Held-out test results (1,115 messages):**
- Accuracy: **97.31%**
- Spam precision: **100.00%**
- Spam recall: **79.87%**
- Spam F1-score: **88.81%**

The confusion matrix showed that 119 spam messages were correctly detected and 30 spam messages were missed. This helped me understand why evaluating an AI model requires more than accuracy alone.

I documented the problem, intended users, dataset, methodology, success criteria, constraints and limitations. The project and full evaluation report are available here:
https://github.com/rohith732/SWYNEX-AI-Problem-Design-/

This task helped me turn a real-world problem into a focused AI experiment with measurable results.
