Completed Task 4 — Final Data Analytics Project as part of my Data Analyst Internship with @SWYNEX Technologies.

For this final case study, I built an end-to-end analytics workflow using the UCI Adult Census Income dataset (historical 1994 US Census data).

What I worked on:
• Defined the analysis problem and documented the dataset
• Cleaned the data, handled missing markers, and removed exact duplicate records across the train/test files
• Performed exploratory data analysis on income, education, occupation, age, and weekly working hours
• Built an interactive Streamlit dashboard with filters, visualizations, a cleaned-data preview, and CSV export
• Summarized business insights and documented dataset limitations

Tools: Python, Pandas, Streamlit, Plotly, GitHub

GitHub project: https://github.com/rohith732/SWYNEX-AI-Problem-Design-/tree/main/Task4-Final-Data-Analytics

I learned how to turn raw data into a reproducible analysis and an interactive dashboard while communicating findings responsibly.
