# Task 3 demo walkthrough (60–90 seconds)

1. Introduce the SWYNEX Task 3 dashboard built on the UCI Adult / Census Income dataset.
2. Point out the four KPI cards: filtered record count, high-income share, average age and average weekly working hours.
3. Demonstrate the age slider and sidebar filters. Explain that KPIs and charts update with the selected filters.
4. Scroll through income distribution, age distribution by income, education vs income and top occupations.
5. Show the filtered data preview and CSV download.
6. Explain that the dashboard turns earlier cleaning and EDA work into an interactive way to explore and communicate findings.

Do not state performance improvements or causal conclusions that the descriptive dataset does not establish.
