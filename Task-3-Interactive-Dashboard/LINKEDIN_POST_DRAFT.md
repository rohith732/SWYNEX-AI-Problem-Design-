# LinkedIn post draft — SWYNEX Task 3

Completed **Task 3 – Interactive Dashboard** as part of my Data Analyst Internship at **@SWYNEX Technologies**.

For this task, I transformed the UCI Adult / Census Income analysis from my earlier tasks into an interactive dashboard using **Python, Streamlit, Pandas and Plotly**.

The dashboard includes:
- KPI cards for record count, high-income share, average age and average weekly working hours
- Interactive charts for income distribution, age groups, education and occupation
- Filters to explore data by age, workclass, education, gender, occupation, marital status and income category
- A filtered-data preview and CSV download option

This task helped me understand how to turn exploratory data analysis into a clear, interactive tool that makes data easier to explore and communicate.
